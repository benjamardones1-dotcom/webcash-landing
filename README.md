# Latitud Sur — Landing Page

Sitio web profesional de **Latitud Sur Capacitaciones**, consultora chilena de desarrollo organizacional.

## Estructura

```
public/
  index.html       — Página principal (HTML autocontenido)
  banner_lats.jpg  — Logo horizontal con tagline
  foto_lats.png    — Logo cuadrado del círculo tricolor
```

## Desarrollo local

```bash
npx serve public
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

## Despliegue

El sitio es estático y se puede desplegar en cualquier hosting que sirva archivos HTML:

- **Vercel**: Configura el directorio de salida como `public/`
- **Netlify**: Publish directory: `public/`
- **GitHub Pages**: Sirve desde la carpeta `public/`
